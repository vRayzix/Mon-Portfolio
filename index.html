Réseaux

SAE 1.02 : Architecture Succursale

EVE-NG • Cisco IOS • OSPF • VLANs

Conception de l'architecture réseau complète d'une succursale d'entreprise sous EVE-NG, avec connectivité, segmentation et sécurité via matériel Cisco simulé.

Topologie logique — Routeurs & Switchs Cisco

Implémentation technique

  • Segmentation VLAN : Direction, Employés, Wi-Fi Invités — isolation des flux
  • Routage Inter-VLAN : Router-on-a-Stick / SVI pour communication contrôlée
  • Services DHCP/DNS : Serveur DHCP relayé, attribution dynamique des IPs
  • Protocoles : OSPF (routage dynamique vers le siège) + NAT (accès Internet)
Preuve DHCP — Serveur Linux vers postes VPC

Compétences validées

  • AC11.03 — Configurer les fonctions de base du réseau local
  • Maîtrise de la CLI Cisco (IOS) et commutation
  • Virtualisation avancée avec EVE-NG

SAE 1.03 : Installation & Mesures

Câblage • Wi-Fi Audit • Packet Tracer • PoE

Projet transversal couvrant la chaîne complète d'une infrastructure réseau : connectique physique, audit Wi-Fi terrain et simulation logique sous Packet Tracer.

Simulation complète de l'infrastructure réseau

Infrastructure physique

  • Câblage structuré : Câbles Cat 7 (norme TIA-568B), sertissage RJ45, montage noyaux femelles
  • Analyse PoE : Switch Cisco Catalyst 2960 — Tension : 54V, Puissance AP : 13W, Intensité : 0.24A
  • Matériel : Cisco AIR-AP1231G, Switch WS-C2960, analyseur de spectre Wi-Fi

Audit Wi-Fi (Heatmaps)

  • Cartographie des zones blanches et interférences (2.4 GHz / 5 GHz) via Acrylic Wi-Fi
  • Mesures d'atténuation des matériaux (Placo vs Béton) et analyse des débits
Accès réussi au site uha1.fr via Packet Tracer

SAE 1.05 : Traiter des Données

PowerShell • Python • PySide6 • JSON

Solution logicielle complète pour identifier les fichiers volumineux sur un serveur et les supprimer via une interface graphique sécurisée.

Structure modulaire du projet

Architecture modulaire

  • Orchestrateur (sae.ps1) : Script PowerShell — préparation de l'environnement, vérification des dépendances, sécurité
  • Moteur (analyse.py) : Parcours récursif (os.walk), tri par taille, export JSON
  • Interface (main_gui.py) : PySide6 (Qt) — affichage graphique et tabulaire des données
Interface graphique — Répartition de l'espace disque

Problèmes résolus

  • Chemins UNC : Montage automatisé via PowerShell (New-PSDrive) pour les dossiers réseau
  • Précision : Division flottante + round() pour les fichiers < 1 Mo

Compétences validées

  • AC11.02 — Algorithmes complexes (tri, récursivité), structures JSON
  • Scripting système avancé et interactions inter-processus
  • Conception IHM orientée utilisateur avec Qt
